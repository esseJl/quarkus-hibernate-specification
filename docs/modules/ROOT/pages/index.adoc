= Quarkus Hibernate Specification

This extension provides a Spring-Data-JPA-Specification style dynamic query builder
for both Hibernate ORM and Hibernate Reactive.

== Installation

[source,xml]
----
<dependency>
  <groupId>io.quarkiverse.hibernatespecification</groupId>
  <artifactId>quarkus-hibernate-specification</artifactId>
  <version>${quarkus-hibernate-specification.version}</version>
</dependency>
----

== Usage

[source,java]
----
@Inject
SpecificationBuilder builder;


// Blocking
List<Order> orders = builder.find(Order.class, request);
----
